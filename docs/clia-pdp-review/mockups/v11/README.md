## 정확하고 부드러운 동시 스크롤

- **스크롤 막대를 하나로 합쳤습니다.** 화면 오른쪽 끝 막대 하나가 양쪽을 같이 움직입니다. 양쪽 내용은 각자 스크롤하지 않고 같은 프레임에서 `transform`으로 함께 옮겨지므로, 한쪽이 늦게 따라오거나 떨리지 않습니다(v10은 한쪽 스크롤 이벤트로 다른 쪽을 고쳐 써서 한 박자 늦을 수 있었음).
- 규칙은 v10과 같습니다. 콘텐츠 폭 기준 같은 거리로 움직이고(`오른쪽 = min(s, 끝)`, `왼쪽 = min(s × 왼쪽폭/오른쪽폭, 끝)`), 짧은 쪽은 끝에서 「기다리는 중」을 띄우고 멈춥니다.
- **자리를 미리 잡습니다.** 상세 이미지 크기(폭·높이)를 미리 알아서([collect_v11.py](./collect_v11.py)가 JPEG 머리 16KB만 GET으로 읽음) 이미지가 늦게 와도 위치가 밀리지 않습니다.
- 검사([check_v11.js](./check_v11.js)), 28개 × Shopee·Lazada:
  - 이미지를 다 받은 뒤 다시 재도 체크리스트 기준점이 1px 넘게 움직인 곳: **0**
  - 6개 지점에서 실제 위치와 규칙의 차이 0.6px 초과: **0**
  - 이미지 비율이 원본과 1% 넘게 다른 것: **0**

## 스크롤 체크리스트

오른쪽 칸(340px)에 채널별 항목이 있습니다.

| 항목 | 기준점(결과 쪽) | 보는 것 |
|---|---|---|
| PDP 요약 | 요약 맨 위 | Shopee: 줄바꿈·글머리표가 깨지지 않았는지. 공통: lg.com에 없는 내용·과장이 없는지(AI가 쓴 글), 숫자·스펙 값 |
| 상세 이미지 n | 그 이미지 맨 위 | 왼쪽 lg.com 같은 부분과 문구·숫자가 같은지, 잘리거나 빠진 곳. **그 이미지에 든 lg.com 섹션 제목**을 같이 보여 줌 |
| Shopee에 안 들어감 | 「아래 n장은 넣지 않음」 줄 | 앞 12장·3,000자 규칙으로 빠지는 이미지에 꼭 필요한 내용(스펙·주의 문구)이 없는지 |
| 자동 대조로 못 찾은 lg.com 섹션 | 맨 끝 | 결과 이미지에 들어 있는지. 정말 빠졌으면 「다름」 후 반려 |

- **지금 볼 곳:** 화면 위 35% 선을 지난 마지막 항목입니다. 체크리스트에서 펼쳐지고, 결과 쪽에 빨간 테두리가 그 구간을 따라갑니다.
- **봤음 ✓:** 화면 위 55% 선을 지나면 자동으로 켜집니다. 끝까지 내리면 남은 항목도 켜집니다.
- **다름:** 항목마다 「다름」을 누르면 빨간 표시가 생기고 코멘트에 「상세 이미지 5: 다름」이 붙습니다.
- **승인 조건:** 두 채널의 항목을 모두 봤고 「다름」이 없을 때만 「승인」이 열립니다. 상세 이미지 항목은 두 채널이 같은 슬라이스라 한쪽에서 보면 둘 다 봄으로 칩니다. 요약과 Shopee 제외분은 채널마다 봐야 합니다.
- 항목을 누르면 그 위치로 바로 갑니다.
- 섹션 제목은 운영 저장본 `mirror.sections`의 「## 」 제목을 슬라이스 alt(이미지 속 글)에서 찾아 붙였습니다. TV처럼 섹션이 많은 제품은 못 찾는 제목이 많습니다(예: OLED48C6PSA 20개). 정말 빠진 건지 대조가 덜 된 건지는 사람이 봐야 해서, 별도 항목으로 둡니다.

## 운영 반영 계획 (승인 전 표시 · 다운로드 잠금) — 아직 코드 없음

요청: 「승인이 안 됐으면 Build 페이지에도 승인 전이라고 표시하고, 승인이 완료돼야 다운로드되게.」

지금 운영에는 승인 상태를 저장하는 곳이 없습니다. 그래서 다음이 필요합니다.

1. **승인 저장:** `out/<slug>/approval.json` (상태·누가·언제·체크리스트·일괄 여부·승인한 슬라이스 해시) + 버킷 동기화. `GET /api/v1/approvals?slugs=…`, `POST /api/v1/approvals/:slug` (승인·반려), `POST /api/v1/approvals/bulk`.
2. **빌더**(`shopee-lazada-pdp/index.html`): 제품을 열면 승인 상태를 읽어 「승인 전 / 승인됨」 배지를 보여 줍니다. 승인 전이면 다음 버튼을 잠급니다.
   - `btnDownload` · `btnDownload2` · `btnDownload12` · `btnDownload12b`(이미지 ZIP)
   - `btnCopyHtml` · `btnCopyImgHtml`(HTML 복사)
   - 승인 뒤 내용이 바뀌면(슬라이스 해시가 다르면) 다시 「승인 전」입니다.
3. **벌크 엑셀**(`GET /api/v1/bulk/jobs/:job/file`): 승인 안 된 행이 있으면 서버에서 막습니다(전체 승인 후 엑셀 — 이전 결정).
4. **켜는 시점:** 이전 결정대로 서버 설정(예: `APPROVAL_GATE=1`) 뒤에 두고 기본은 꺼 둡니다.
   - 지금 바로 켜면 승인 화면이 운영에 생기기 전이라 모든 다운로드가 막힙니다.
   - 꺼져 있을 때도 배지는 보여 줄지 정해야 합니다.
